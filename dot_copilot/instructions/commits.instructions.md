## Auto-Commit

**Commit when ALL true:**
- Single concern (1 feature/fix/refactor, ≤5 files changed)
- ≤100 lines diff (excludes: tests, autogenerated, env-only configs)
- Tests pass + new code has test coverage
- No open TODOs in changed code
- No changes to: exported APIs, config schemas, protected files (see below)

**Protected files (always require explicit user review):**
- Auth, crypto, secret, password, token, key, vault (case-insensitive in path)
- .github/workflows/, infrastructure/, deployment/
- .env, secrets.yml, credentials.json
- Project overrides: .copilot/project-config.md

**If uncertain:** Ask user before committing.

**Tie-breaker:** Ask user. If no response, apply most restrictive criterion.
